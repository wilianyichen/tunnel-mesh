# Tunnel Mesh 使用教程（小白友好版）

## 这是什么？

Tunnel Mesh 让你从 A 电脑连接到 B 电脑，即使 B 在内网也能连。

**简单说**：在 B 上运行脚本，复制一段「契约文书」，在 A 上粘贴，就能连接了。

---

## 两种连接方式

### 平等契约（双向直连）

```
┌─────────┐          ┌─────────┐
│  电脑A  │ ←──────→ │  电脑B  │
└─────────┘  网络互通  └─────────┘
```

- 两台电脑在同一网络，或都有公网IP
- **双方都要运行脚本，交换契约文书**
- 完成后双方都能互相 SSH 访问

### 主仆契约（单向连接，需中转）

```
┌─────────┐     ┌──────────┐     ┌─────────┐
│  电脑A  │ ──→ │ 契约之塔  │ ←── │  电脑B  │
│ （主）  │     │（中转服务器）│    │ （仆）  │
└─────────┘     └──────────┘     └─────────┘
      ↑               ↑               ↑
    SSH连接       公网IP        内网主动连接
```

- B 在内网，A 在外网
- **需要一台有公网IP的服务器（契约之塔）**
- B 运行脚本，A 粘贴契约文书
- 完成后 A 能访问 B

---

## 快速开始

### 情况 1：平等契约（双向直连）

#### 在电脑 A 上：
1. 双击 Tunnel Mesh → 选择 **[2] 撰写契约文书**
2. 选择 **[1] 平等契约**
3. 复制输出的契约文书
4. 发给电脑 B

#### 在电脑 B 上：
1. 运行 `linux-export-config.sh`
2. 选择 **[1] 平等契约**
3. 复制输出的契约文书
4. 发给电脑 A

#### 双方：
1. 选择 **[1] 缔结新契约**，粘贴对方的契约文书
2. 选择 **[3] 契约之仪** 启动连接
3. 完成！双方都能互相访问

---

### 情况 2：主仆契约（单向连接）

#### 在仆端（内网服务器）：
```bash
curl -sSL https://raw.githubusercontent.com/wilianyichen/tunnel-mesh/main/linux-export-config.sh | bash
```
选择 **[2] 主仆契约**，按提示输入契约之塔信息。

#### 在主端（你的电脑）：
1. 双击 Tunnel Mesh
2. 选择 **[1] 缔结新契约**
3. 粘贴仆端的契约文书
4. 选择 **[3] 契约之仪**

**完成！**

## 安装

### Windows 安装
1. 下载 `windows-install.bat`
2. 右键 → 以管理员身份运行
3. 桌面出现 **契约大厅** 图标

### Linux 安装
无需安装，直接运行脚本。

## 常见问题

### Q: 什么是「契约之塔」？
A: 就是你的云服务器（阿里云/腾讯云等），它有一串公网IP。

### Q: 契约之塔的参数什么意思？
A:
- **名称**：给中转服务器起个名，方便记（如 aliyun）
- **公网IP**：你云服务器的公开地址，如 123.123.123.123
- **SSH端口**：云服务器的SSH端口，一般是 22
- **SSH用户**：你用哪个账号登录云服务器，一般是 root

### Q: 平等契约和主仆契约怎么选？
A:
- 两台电脑在同一网络 → 平等契约
- 两台都有公网IP → 平等契约
- 只有一台有公网IP → 主仆契约
- 一台在内网 → 主仆契约

### Q: 重启后还能连吗？
A: 能！服务会自动启动。
