# Tunnel Mesh

> Linux: `bash tunnel-mesh.sh` / Windows: 双击 `tunnel-mesh.bat`

## 快速开始

**Linux**：导出身份卡或导入对方身份卡
```bash
bash tunnel-mesh.sh
```

**Windows**：粘贴 Linux 生成的隧道命令，自动创建开机自启
```
双击 tunnel-mesh.bat → [1]导入 → 粘贴 ssh -R ... 命令
```
